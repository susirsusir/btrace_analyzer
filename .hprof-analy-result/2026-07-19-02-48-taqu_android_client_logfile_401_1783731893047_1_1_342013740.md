## 附录

### 分析方法

1. 使用 `hprof-conv` 将 hprof-libs 转换为标准 hprof-heap 格式
2. 使用 HeapDumpStarDiver 转换为 Parquet 格式
3. 使用 DuckDB SQL 进行交互式查询分析

### 格式说明

- **Parquet**: 列式存储格式，适合大规模数据分析
- **Robo Mode**: HeapDumpStarDiver 优化的输出模式，使用裸 ID 引用，类型索引分离
- **对象 ID**: 使用 UBIGINT 类型，引用通过 obj_id 关联
